# 伊莫家园生产计算器

《伊莫》家园生产规划工具：填好你的条件，点一下"计算最优方案"，就得到产值最高的种植与生产安排。全部计算在你的浏览器里完成，数据只保存在你自己的设备上。

## 快速上手

1. 在"生产计算"页顶部的条件栏设置**当前等级**（默认 10 级，清空＝不限）、**时长**、**工作系数**；
2. 在"规划配置"里按需填写（都可留空）：
   - **数据管理**：改各建筑的拥有数量，改完约 1 秒自动重算；
   - **工作效率**：给单个建筑设独立效率%，不填的跟随全局系数；
   - **存量资源**：填你已有的资源数量，会当作可用原料参与规划；
   - **自定义生产**：指定某建筑保底生产某产物，同一建筑可加多行（如 1 块月露萝卜＋1 块盈月椒，其余地块自动最优）；
3. 点**计算最优方案**，查看结果。

## 结果怎么看

- **概览卡片**：最优总产值、整数可行方案、出售种类、每小时净利润；
- **种植与生产安排**：田地和林地有**逐块时间轴**——每一块地种什么、种多久、第几小时换茬一目了然；其他建筑显示占比条与"X块×Y轮·时长"的整数安排；
- **图表**：出售价值构成、各产物净利润、净收益排行（悬停可看材料明细）；
- **方案明细**：每个建筑每个产物的轮次与占用；展开可看物料平衡（产出/消耗/每小时速率/消耗去向）与未参与的配方及原因。

## 两个开关

- **赛季配方**：默认不勾选＝不使用赛季作物（获取渠道有限）；勾选后参与自由规划。无论是否勾选，你在"自定义生产"里设定的赛季产物都会按设定数量精确参与，其衍生加工（如月露萝卜花、烤盈月椒）也会自动安排；
- **懒人模式**：原料类建筑（田地/林地等）每块地全程只种一种产物，省心不换茬。可搭配：
  - **原料配方**：限制每种建筑最多用几种产物（1＝整齐划一；自定义生产不占额度）；
  - **换配方**：允许全程统一切换 1~2 次配方（所有原料建筑同时换）。

## 能力图鉴

页面顶部的"**能力图鉴**"页签用来挑选合适的伊莫去建筑上岗（数据来自官方 wiki 图鉴，208 个形态）：

- **建筑岗位推荐**：每个建筑偏好的条件——圆形徽章是推荐性格（后天养成属性，仅供参考），后半段是先天条件（属性/能力/家族）。点击卡片自动按该条件筛出合适的伊莫；田地和林地无需推荐不显示，还没录入条件的建筑（如星落吊床、花舞风车）显示"数据待补充"；
- **伊莫筛选**：能力类型（火/草/水/土/电/冰/风/暗/光/搬运/手工/游玩/制香，可多选=须同时具备）、能力等级（全部 / Lv2+ / Lv3+ / Lv4+）、名称或编号搜索（如"蓬蓬羊"或"018"）。

## 家园规划

「家园规划」页签在 320×320 的网格画布上摆放建筑（每块土地 80×80，4×4 共 16 块，按等级解锁）：

- **摆放**：左侧选建筑点击画布放置，拖动移动，R 键旋转，右键拆除；建筑可跨土地格，但必须都在已解锁土地上；滚轮缩放、空白处拖动平移；
- **数量**：与家园等级绑定，不可超放。10/11/12 级有完整官方解锁数据，切换等级自动填入对应数额
  （如 12 级田地 26、林地 13、发电桩 1、电线杆 6）；其他等级暂无完整数据，依赖生产计算页登记的数量；
- **作物**：「导入生产方案」把生产计算的种植安排按顺序分配到田地/林地；点击地块也可手动指定（手动的不被覆盖）；可开启"作物色模式"按作物换底色；
- **光照与温度**：日光灯/热能炉/制冷机有 36×36 影响范围（虚线框可开关），热能炉可切 🔥温暖/🔥🔥炎热，制冷机可切 ❄凉爽/❄❄冰冻；光照与温度影响作物生长效率；
- **电力系统**（12 级解锁）：噼啪发电桩（8×8，覆盖 44×44，发电 600W）与噼啪电线杆（6×6，覆盖 28×28，
  需与发电桩或其他已联通电线杆的覆盖区任意 1 格重合才算联通中转）；覆盖内耗电建筑的接入
  顺序 = "需要原材料的建筑"优先（配方含输入，见 building_power 表），其余建筑用剩余功率
  （避免发电空转），负载不超过总供电，功率不足时后者自动让位；
  **实时效率 = min(120%, 总供电 ÷ 接入总功耗)**（冗余 ≥20% 即为 120%）；
  顶部统计显示 发电功率/接入座数/负载/实时效率，效率低于 100% 红字提醒；悬停建筑显示 通电与实时效率；
  田地/林地/游玩类设施不参与电力；发电桩由一键布局自动选址（覆盖接入功率最大），电线杆需手动摆放；
- **保存与分享**：布局自动存本机，可一键导出 PNG。

## 其他说明

- **加工链**：木块/矿砂等材料会自动连同林地/矿山的副产物一起，加工到当前等级能做的最高层级（层压木梁、致密木构件、微晶矿板等）；
- **时间口径**：工作量型建筑每轮时间＝工作量÷工作系数；生长型按生长时间；
- **收益口径**：净利润只计实际卖出的盈余，自用材料不计；材料成本按售价折算；种植类每轮扣一粒种子价；
- **数据保存在哪**：全部在本机浏览器（localStorage），换设备或清浏览器数据不会同步；想重置就清除站点数据或逐项删除；
- **手机可用**：页面自适应手机屏幕。

## 常见问题

- **改了建筑数量没反应？** 会自动重算，稍等 1 秒即可；
- **提示"自定义生产不可用"？** 该产物当前等级不够或材料无来源，看提示里的原因；
- **提示与"整齐划一"冲突？** 同一建筑的自定义产物数超过了"原料配方"限制（自定义不占额度，但自由部分仍受限），放宽限制或减少自定义项。

## 积木图纸

第 4 个页签「积木图纸」：上传图片 → 量化到游戏 74 色积木色板 → 2D 搭建图纸
（每格 = 1 积木 = 2×2×2，默认 40×40，最大 80×80；固定 stretch 拉伸采样、
不做抖动；默认透明留空，可选铺白底/自定义底色；OKLab 最近色、
小区域清理（默认最小区域 1，即不清理）、色板芯片右键禁色）。
图纸生成后可直接手绘修改：左键点色板选画笔、图纸上左键拖动绘制、
右键拖动擦除、橡皮擦/清空按钮；颜色统计与图例在图纸上方实时更新。
画布支持缩放（＋/− 按钮、Ctrl+滚轮锚点缩放、适应宽度；缩小下限自动钳制到整图可见的全貌尺寸），放大后色块内
自动显示颜色名（按底色深浅自动反色、字号自适应不溢出格子）。
支持「拼豆/网格图纸」模式：自动识别网格区域（排除行列标号表），
按宽×高逐格取主色（众数，忽略格内字母编号），白底无字格留空，
可用裁边微调；识别失败或偏移时手动收边即可。
支持 JSON 导入（cells / cells_rle / placement 三种来源，含校验）与
JSON 导出（unit=2、layers=1，含游戏放置清单）；另有 PNG/SVG/CSV 导出。
详见《积木图纸生成器说明.md》。
